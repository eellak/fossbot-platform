# Education system student guide

## Start and resume

Open **Courses**, choose a public course or a shared unlisted link, and select **Start course**. **My courses** shows progress and returns you to the next unfinished lesson. Your progress and workspace are saved to your account, not GitHub.

Each lesson keeps instructions, code, simulator, sensor evidence, questions, and results in one workspace. On a tablet or narrow laptop, use the named tabs; switching panes does not reset the editor or simulator.

## Code, simulator, and autosave

The save status appears in the lesson header. If saving fails, retry when the connection returns. If another tab saved a newer revision, reload before editing further so one tab does not silently overwrite the other.

Some lessons **Start with the previous lesson's saved code**. Open and save the previous lesson first. The copy happens once; later edits in the old lesson do not replace the new workspace.

- **Reset simulation** moves the robot and stage objects back to their starting state while keeping code.
- **Reset code** restores the lesson's starting code and asks for confirmation. It does not reset the simulator.
- Every run starts from a fresh simulation state.

## Questions, sensors, and missions

Questions explain whether an answer is correct and allow another try when the lesson permits it. A sensor chart includes a text summary; choose a sensor to inspect its live and summary values.

Mission feedback separates required objectives, failure conditions, and optional challenges. Reset or retry starts a new attempt. Movement actions count robot commands, while path distance measures how far the robot travelled. Scores and personal bests are optional optimization feedback and do not turn an unsuccessful mission into a completed one.

## Course updates and privacy

An **Update available** notice never changes your open work. You can:

1. continue the current version;
2. review added, changed, removed, and stage-changed lessons;
3. choose **Update course**.

Unchanged compatible work is preserved. A changed lesson starts from its new setup without automatically merging code. Use **View previous code** to read and copy older saved work when available.

Class leaderboards use an alias, are visible only inside the class group, and require opt-in. Opting out keeps your personal results private and hides the board.

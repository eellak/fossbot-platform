# Frontend UI instructions

Before changing frontend UI:

- Read `DESIGN.md`.
- Inspect at least one canonical browsing page: Dashboard, student Courses, teacher Courses, or Stages. For editor work, also inspect the closest approved editor.
- Reuse `ApprovedTheme.ts`, `theme/Components.tsx`, `shared/PageHeader.tsx`, and existing shared workspace, notification, card, field, and status components before adding local styling.
- Preserve the approved FOSSBot identity and the distinction between browsing and editor layouts. Do not redesign unless the user explicitly requests it.
- Keep exact token values in their owning theme or shared component; update `DESIGN.md` when an approved system decision changes.
